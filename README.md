# 우리집 가계부 (창진 & 효연)

부부가 함께 쓰는 웹 가계부. 모바일/PC 반응형. 참고 구글시트 가계부를 웹앱으로 재구성했습니다.

## 실행 방법

```bash
cd budget-app
npm install      # 최초 1회
npm run dev      # 개발 서버 (http://localhost:5180)
```

빌드해서 배포하려면:
```bash
npm run build    # dist/ 폴더 생성 → 정적 호스팅(Netlify/Vercel 등)에 업로드
npm run preview  # 빌드 결과 미리보기
```

## 사용자 (창진 / 효연)

첫 화면에서 **창진 / 효연**을 선택해 들어갑니다. 사이드바의 프로필 칩으로 전환할 수 있어요.

## 추가 기능

- **☁ 클라우드 동기화** (설정 → 클라우드 동기화): 무료 Supabase 프로젝트를 만들고 URL·anon key를 넣으면 두 기기/두 사람이 실시간 공유. 설정 안에 SQL 스크립트와 설정법이 들어 있음. 미설정 시 자동으로 로컬만 사용.
- **🔔 반복 지출 알림**: 고정내역/할부의 다가오는 결제일을 오늘 기준으로 계산해 상단 벨과 대시보드 카드에 표시(휴일옵션 반영). 브라우저 알림도 지원.
- **🧾 영수증 첨부**: 월간내역 각 행에 사진 첨부(자동 압축 저장), 썸네일·뷰어.
- **🚦 예산 경고**: 월간 지출이 예산 대비 80% 임박(🟠)/초과(🔴)면 색·아이콘·진행바로 경고.

## 데이터 저장

- 기본: **이 기기(브라우저) localStorage**에 자동 저장 (오프라인 동작)
- 기기 간 이동(클라우드 미사용 시): 설정 → **백업 내보내기/가져오기** (JSON)
- 클라우드: 설정에서 켜면 Supabase에 프로필별로 동기화(마지막 저장 우선)
- 저장 계층은 `src/data/storage.js` + `src/data/cloud.js` 로 분리

## 폴더 구조

```
src/
  data/         # 상태·저장소·기본값·계산(selectors)·할부 로직
  components/   # 차트(recharts) · UI · 입력 필드 · 프로필 선택
  views/        # 7개 시트
  utils/        # 포맷 · 한국 공휴일/영업일 계산
```
