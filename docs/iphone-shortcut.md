# 아이폰 단축어로 카드 승인 문자 자동 수집하기

카드 결제 → 승인 문자 도착 → 단축어가 자동으로 Supabase `inbox`에 전송 → 가계부 앱 **월간내역 > 문자 자동 수집**에서 확인 후 반영.
한 번 설정하면 이후에는 손댈 것이 없습니다.

## 0. 준비
- 카드사 **승인 문자(SMS) 서비스** 신청 (우리카드, KB국민카드). 카드 앱 푸시 알림은 단축어가 읽을 수 없어서 문자가 필요합니다.
- 앱 설정 → 클라우드 동기화가 켜져 있어야 하고, Supabase SQL Editor에서 `inbox` 테이블 SQL을 실행해 둡니다 (설정 화면 '설정법 보기'에 있음).
- Supabase **Project URL**과 **anon public key**를 준비합니다 (앱에 넣은 것과 같은 값).

## 1. 단축어 만들기 (창진 폰 예시)
1. **단축어** 앱 → 아래 **자동화** 탭 → **+** → **메시지**
2. 조건: **메시지에 포함** = `승인` (취소 문자도 받으려면 자동화를 하나 더 만들어 `취소`로)
   - 보낸 사람을 카드사 번호로 지정하면 더 정확합니다 (우리카드 1588-9955, KB국민카드 1588-1688 — 실제 문자 발신번호 확인).
3. **즉시 실행** 선택 (iOS 17 이상), 다음
4. 동작 추가: **URL 콘텐츠 가져오기**
   - URL: `https://<프로젝트>.supabase.co/rest/v1/inbox`
   - 방법: **POST**
   - 헤더
     - `apikey` : `<anon key>`
     - `Authorization` : `Bearer <anon key>`
     - `Content-Type` : `application/json`
     - `Prefer` : `return=minimal`
   - 본문 요청: **JSON**
     - `profile` (텍스트) : `창진`
     - `body` (텍스트) : 변수 **단축어 입력** (또는 '메시지' → 내용)
5. 완료.

효연 폰에서도 똑같이 만들고 `profile`만 `효연`으로 바꿉니다.

## 2. 확인
- 카드로 소액 결제 → 1~2초 뒤 Supabase Table Editor의 `inbox`에 한 줄이 생기면 성공.
- 가계부 앱 월간내역 화면에 **문자 자동 수집 N건** 카드가 뜨고, 분류를 고른 뒤 **반영**하면 데일리 내역에 들어갑니다.
- 문자 형식이 달라 '해석 실패'가 뜨면 문자 원문을 알려주세요. `src/data/smsParser.js`만 고치면 됩니다.

## 보안 메모
- anon key는 비밀번호처럼 다루세요. 단축어 안에만 넣고 캡처·공유하지 않습니다.
- inbox에는 delete 정책이 없어 앱이나 단축어로 문자를 지울 수 없습니다. 다만 같은 anon key로 기존 `budgets`는 읽고 쓸 수 있으니, 로그인 기반 정책으로 강화하는 것을 다음 단계로 검토합니다.
